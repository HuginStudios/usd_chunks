# usd_chunks — Agent Instructions

This project's canonical AI-agent instructions live in [`CLAUDE.md`](CLAUDE.md) — project
overview, architecture, and conventions. If your tool reads `AGENTS.md` instead of
`CLAUDE.md`, treat that file as identical to this one; it isn't Claude-specific despite
the name.

Any personal, machine-local tool config (e.g. an individual's search-indexing setup)
lives in each contributor's own `.claude/settings.local.json` / `.claude/CLAUDE.md`,
not here — those aren't shared across the team.
